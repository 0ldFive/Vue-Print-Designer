# AI 生成模板 · 设计

**目标**：在设计器内用自然语言生成与迭代修改打印模板，预览确认后应用到画布；AI 作为可热插拔模块，关闭时不进入产物、不加载代码。

**方案**：模型每轮返回完整模板 JSON，前端规范化修复后以临时快照注入画布预览，用户确认后才写入历史栈；AI 全部代码收敛在 `src/ai/`，由设置开关控制启停，启用后通过动态 `import()` 懒加载。

**全局约束**：

- 不新增运行时依赖，只用 `fetch` + `ReadableStream`
- 元素类型仅限现有 10 种 `ElementType` 白名单
- AI 输出坐标固定为 px，与 store 的 `unit` 解耦
- 模型配置（含密钥）仅存 localStorage，按 `crudScopeId` 隔离
- 开关默认关闭；关闭时不加载 AI chunk、不显示入口、不注册任何 AI 逻辑
- AI 的 store、组件、composable、文案、类型全部位于 `src/ai/`，主工程不得静态引用其中的业务代码
- AI 面板纳入现有 `useFloatingPanels` 体系（拖动、缩放、置顶、层序统一）
- 新增主工程文案（仅设置开关）需覆盖 6 种语言；AI 面板文案由 `src/ai/locales/` 自带，按语言一文件

## 现状与问题

- 模板数据为 `{ pages, canvasSize, ... }`，`loadTemplateData` 可整份载入，但没有任何生成能力。
- 组件库纯前端、无后端，模型访问只能在浏览器侧完成。
- 模型输出不可信：类型、坐标、样式、变量绑定都可能非法，直接载入会污染画布与保存数据。
- 若把 AI 逻辑写进主工程，会持续增大组件库体积，且并非所有使用方都需要该能力。

## 方案与取舍

**方案 A：整张 JSON 重写 + 画布内临时预览（采用）**

- 每轮携带当前模板与用户指令，模型返回完整模板 JSON。
- 规范化修复后临时替换 `pages` 渲染真实画布，确认条提供应用 / 重新生成 / 放弃。
- 优点：协议最简单、模型出错率最低、预览 100% 保真、新建与修改共用一条链路。
- 代价：每轮 token 略大（模板通常只有几 KB）。

**方案 B：JSON Patch 增量修改（否决）**

- 模型易产出错误路径与失效 id，纠错代码量超过主功能；还需额外做低保真缩略预览组件。

**方案 C：Tool Calling / Structured Outputs（否决）**

- 浏览器直连任意「OpenAI 兼容」端点时，function calling 与严格 JSON Schema 支持度参差不齐，部分中转服务直接不可用。

**热插拔方案取舍**

- 采用「运行时开关 + 动态 import」（否决构建时剔除）：无需重新构建即可启停，且关闭时同样不下载 AI 代码，满足两种场景。
- 采用「目录整体收敛」（否决按工程习惯分散）：`src/ai/` 即模块边界，删除该目录并移除 4 处接入点即可彻底移除功能。
- 开关默认关闭（否决默认开启）：AI 属于可选能力，默认不引入模型配置负担与额外体积。

## 热插拔设计

**开关**

- 位置：设置面板新增「AI 生成模板」开关。
- 持久化：`print-designer-ai-enabled`（全局），由 `src/composables/useFeatureFlags.ts` 统一读写并广播变更。
- 默认值：`false`。

**懒加载边界**

- 主工程只保留 4 个接入点，且都不静态引用 `src/ai/` 业务代码：
  1. 设置开关（读写 flag）
  2. 工具栏 AI 按钮（`v-if` flag，点击后 `defineAsyncComponent` 加载面板）
  3. `PrintDesigner` 异步组件挂载点（未打开面板不会请求 chunk）
  4. `web-component` 对外方法（方法内部 `await import("@/ai/api")`）
- 关闭开关：隐藏按钮、卸载面板、AI store 重置；已下载 chunk 由浏览器缓存，不再执行。

**主工程需要的通用能力（与 AI 无关）**

- `designerStore.previewLocked: boolean`：外部预览锁定标记，AI 模块在预览期间置 true。
- 锁定期间：自动保存跳过、保存/打印/导出禁用、画布覆盖透明遮罩拦截编辑。
- 主工程不知道 AI 的存在，只响应通用锁定标记。

**目录边界**

```
src/ai/
  api.ts / config.ts / types.ts          对外入口与公共定义
  core/       client / prompt / normalize / diff
  state/      store / preview
  composables/useAiTemplate.ts

```

## 提示词与规范化规则

**提示词**

- 输出契约：只返回 `{ name, canvasSize, variables, pages }`，无解释文字。
- 元素契约：白名单类型 + 每类最小必填字段（`table` 必须有 `columns`，`text` 必须有 `content`）。
- 布局约束：原点为页面左上角、单位 px，给出画布尺寸与安全边距，要求不重叠、不出界、字号 ≥ 8。
- 画布尺寸：尺寸知识只存在于提示词，模型按语义判断单据类型自动选尺寸（小票 302×794、面单 378×567、标签 189×113、门票 302×189、工牌 204×325、名片 340×204、证书 1123×794、发票 210×140mm 横向 794×529、A5/A6、报价单/发货单/报表/合同等 A4 794×1123），不因用户没提尺寸就沿用 A4；仅在「修改现有模板且不换单据类型」时保留当前画布；用户显式给出纸张 / 单位（A4、A5、mm、cm、横向）时以用户为准。前端不维护单据类型预设或缩放兜底。
- 版式规范：内置 11 类常见单据的版式要点（增值税发票、小票/收据、快递面单、发货单、标签、工牌、门票/优惠券、报价单/订单、证书/奖状、名片、报表/对账单），写明分区、线框、配色、必备字段与表格列；未列出的类型不允许退回通用表格，按「标题 → 双方信息 → 明细表/键值行 → 汇总（含大写金额）→ 备注 → 签章 → 条码」构件自行组合，未列出的尺寸取最接近的一类，无接近项用 A4。
- 变量约束：项目通过元素 `variable: "@key"`（或 text 内容内联 `@key`）绑定数据。模型需要在 `variables` 中声明用户要填写的字段（lowerCamelCase id + 当前语言 label），值元素 `content` 留空并绑定 `@id`，标签单独成元素；禁止用下划线画空行。已有 `availableVariables` 中的 token 优先复用，同一含义不得重复声明。数组数据用 `isArray: true` 标注。
- 变量落库：`beginPreview` 把模型声明的变量与宿主变量按 id 去重合并（宿主在前），`cancelPreview` 恢复原列表，`commitPreview` 保留；`normalize` 过滤非法 id（空白、标点）与重复 id。
- 修改既有模板时要求保留原有元素 id，保证变更摘要准确。
- 历史只保留最近 3 轮的「指令 + 变更摘要」，不重复携带整份 JSON。

**规范化（`normalize.ts` → `{ template, warnings }`）**

| 层级 | 规则 |
| --- | --- |
| JSON 提取 | 优先 ```json 代码块，其次首个 `{` 到最后一个 `}`，再失败才抛错 |
| 顶层 | `pages` 必须为数组并截断到 5 页；`canvasSize` 完全由模型决定，前端只做 100–5000 合法性校验，缺失或越界时回退当前画布；`variables` 规范化为 `{ id, label, isArray? }` 并去重、过滤非法 id，声明变量同时加入变量校验白名单；预览期同步替换画布尺寸，放弃时恢复（历史栈仍只记录 pages，Ctrl+Z 不恢复尺寸） |
| 元素类型 | 白名单外直接丢弃并记 warning |
| id | 缺失或重复则重新生成 uuid |
| 几何 | 数值化，宽高最小 4；越界夹取回页面内 |
| style | 非对象兜底 `{}`，字号夹取到 8–200，非字符串颜色丢弃 |
| 表格 | `columns` 强制数组；无列时从首行数据推导；`data` 超 200 行截断 |
| 变量 | 不存在的 `@variable` 清空并记 warning |
| 图片 | 非 `http/https/data:` URL 保留但记 warning |

## 状态机与异常

```
idle → generating → previewing → idle（应用 / 放弃）
              └→ error（可重试）
generating --abort--> idle（保留已输出文本）
```

- 预览中再次发送：以当前候选为基线继续修改，新结果直接覆盖候选。
- 切换/加载模板、关闭设置开关：派发 `designer:template-replaced`，丢弃候选快照但不回写 pages；关闭设置开关时额外卸载面板并重置会话。
- 进入自定义元素编辑：关闭面板。
- 错误 code 化后由 AI 自带文案翻译：401 密钥无效、404 端点路径错误、429 限流、网络/CORS、超时、空响应、已取消。
- 规范化后有效元素为 0：视为失败，提示细化描述。
- 端点不支持流式：检测非 `text/event-stream` 响应后回退一次性解析。

## 界面

**AI 浮动面板**（纳入 `useFloatingPanels`）

- 入口：工具栏 AI 按钮 dispatch `designer:toggle-ai-panel`，`PrintDesigner` 切换 `showAiPanel` 并加载异步面板。
- 面板尺寸：默认宽 340px，`heightMode = fit`；可拖动、可缩放、置顶，头部复用浮动面板样式。
- 初始位置：属性面板左侧一列，不与既有面板默认重叠；位置与可见性持久化。
- 内容：消息区（变更摘要卡 + 可折叠 warnings）、输入区（Enter 发送 / Shift+Enter 换行 / 生成中停止）、配置齿轮、未配置引导卡、空状态示例提示词。
- 预览确认条：由面板内部渲染并绝对定位在画布顶部居中，不 Teleport 到 body，保证 Shadow DOM 内样式生效。
- 预览期间：由主工程 `previewLocked` 统一锁定画布与保存、打印、导出；Esc 等同放弃。

## 模型配置与多模态（补充分节）

**模型档案字段**

- `alias`：展示名，可为空；为空时界面回退显示模型 ID。
- `maxInputTokens`：输入上限，默认 8192；仅用于本地历史裁剪估算，不写入请求体。
- `maxTokens`：输出上限，默认 4096；请求字段 `max_tokens`。
- `supportsVision`：是否支持图片输入，默认 false。

**弹窗布局**

- 连接区：模型 ID、接口地址、API Key。
- 高级区（默认收起）：别名 → 采样参数分组（随机度、Top P、最大输入、最大输出、随机种子、存在惩罚、频率惩罚）→ 支持图片输入 → 强制 JSON → 自定义请求头 / 额外参数。
- 两个 token 字段输入框统一显示 `tokens` 单位后缀。
- 编辑时若别名、请求头、额外参数非空或已开启视觉，自动展开高级区。

**输入裁剪**

```ts
// 中文≈1 字/token，其余≈4 字符/token，每张图≈1000 token
const estimateTokens = (text: string, imageCount: number): number;
```

按上限从最早的历史用户消息开始丢弃，至少保留当前指令。

**多模态图片输入**

- 入口：仅当当前档案 `supportsVision` 为真时显示图片按钮，支持点选 / 粘贴 / 拖拽。
- 限制：最多 4 张、单张 ≤5MB、png / jpeg / webp；读入后压缩至最长边 1024、JPEG 0.85 转 dataURL。
- 消息模型新增 `AiMessage.images: AiImageAttachment[]`；气泡展示缩略图，可点开大图。
- 请求：仅当前轮 user 消息使用 vision 数组 `[{ type: "text" }, { type: "image_url", image_url: { url } }]`；历史轮只发文本，避免重复计费。
- 系统提示补充：图片仅作版式与配色参考，输出仍为约定 JSON。

## 对话历史（补充分节）

**数据**

- `AiConversation`：`id`、`title`、`createdAt`、`updatedAt`、`messages`。
- 存储键 `print-designer-ai-conversations:<scopeId>`，与模型配置同样按 `crudScopeId` 隔离。
- 最多保留 20 条，按 `updatedAt` 倒序；标题取首条用户消息前 24 字。
- 写入时机：每轮请求结束（成功 / 失败 / 中止）后统一持久化。
- 体积控制：持久化前剥离 `raw` 与 `errorDetail`，把 `running` / `pending` 步骤归档为 `done`，保留图片 dataURL。
- 配额不足：逐条丢弃最旧会话后重试，仍失败则清空该 scope 的历史。

**交互**

- 头部新增「新建对话」「历史对话」两个按钮，设置与关闭按钮位置不变。
- 历史浮层展示标题、更新时间（当天只显示时分）、消息条数，当前会话高亮；每项可删除。
- 新建对话先保存当前会话再清空消息；切换 / 新建 / 删除时会放弃未确认的预览。
- 生成中禁用新建与切换，避免打断流式请求。
